ENTERPRISE WATER DATA OPEN API

흩어진 수질 데이터를 하나의 표준으로

기업마다 다르게 작성된 수질 데이터의 컬럼명과 용어를 표준코드로 자동 변환합니다. 엑셀·CSV 파일 또는 컬럼 목록을 API로 전송하면 표준화 결과와 검토가 필요한 항목을 반환합니다.

Open API 이용 신청 API 문서 보기

어떤 기능을 제공하나요?

기업이 가진 기존 데이터 형식은 유지하면서 수질 용어만 일관된 표준체계로 변환할 수 있습니다.

컬럼명 자동 표준화

서로 다르게 작성된 수질 용어를 동일한 표준코드와 표준명으로 변환합니다.

T-N → WQ-005 / 총질소
SS → WQ-003 / 부유물질

엑셀·CSV 파일 분석

파일의 컬럼 구조를 분석하여 항목별 표준화 결과를 제공합니다. CSV, XLS, XLSX, XLSM 형식과 최대 100MB 파일을 지원합니다.

검토 항목과 후보 추천

정확하게 판별하기 어려운 용어는 임의로 확정하지 않고 가능한 표준항목, 점수와 검토 필요 여부를 제공합니다.

기업별 전용 사전

기업이 승인한 사내 용어를 전용 사전에 저장합니다. 같은 표현은 이후 요청부터 기존 검수 결과를 바탕으로 자동 매핑됩니다.

이용 절차

이용 신청을 완료하면 발급받은 API 키로 기업의 자체 시스템에서 바로 연동할 수 있습니다.

이용 신청회사 정보, 담당자와 사용 목적을 작성합니다.
신청 완료 및 키 발급신청 내용을 저장하고 기업 전용 API 키를 발급합니다.
API 연동컬럼 또는 파일을 전송하고 표준화 결과를 활용합니다.
결과 확인표준코드, 표준명, 매핑 점수와 추천 후보를 확인합니다.
필요 항목 검수담당자가 애매한 항목의 올바른 표준용어를 선택합니다.
기업 사전 반영승인 결과를 전용 사전에 축적해 반복 작업을 줄입니다.

이런 기업에 적합합니다

  • 여러 사업장의 서로 다른 수질 데이터를 수집하는 기업
  • 수질 엑셀·CSV 데이터를 정기적으로 처리하는 기업
  • 기존 데이터를 표준코드 체계로 변환하려는 기업
  • 반복적인 컬럼 정리와 수작업 검수를 줄이려는 기업
  • 자체 환경관리 시스템에 표준화 기능을 연동하려는 기업
  • 기업 고유 용어를 별도의 전용 사전으로 관리하려는 기업

API 응답 정보

표준화 결과를 자체 데이터베이스, 업무 시스템 또는 검수 화면에 연결할 수 있습니다.

  • 원본 컬럼명
  • 표준코드 및 표준명
  • 자동 매핑 상태
  • 매핑 점수와 추천 후보
  • 검토 필요 여부
  • 기업 전용 사전 적용 여부

이용 안내: 본 Open API는 수질 측정 데이터를 대신 제공하는 API가 아닙니다. 기업이 보유한 수질 데이터의 용어와 컬럼을 분석하여 표준화합니다. 업로드 파일은 표준화 처리에만 사용되며 처리 완료 후 삭제됩니다. 기업별 사전과 API 사용 기록은 다른 기업과 분리되어 관리됩니다.
