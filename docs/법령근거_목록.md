## 4. 정직한 약점 — 발표 전 알고 있어야 할 것

법령 근거가 튼튼한 건 측정항목 쪽이고, 아래는 아직 기준이 약하다.

**① 메타 사전 32행 중 14행이 `미확인 — 공통표준용어 13,176건 대조 필요`**
측정소명·측정일시 같은 핵심은 확인됐지만 절반은 대조가 남았다. 손검증 1순위.

**② 동의어 334건 중 66건이 `DRAFT_AI`(AI 생성 미검증, reliability=inferred)**
`term_sources.csv`에 "법령·실데이터로 확인되기 전에는 근거로 인용 금지"라고 명시돼 있다.
법령에서 직접 온 동의어는 70건(별표1 32 + 먹는물 18 + 별표3 12 + 별표13 5 + 수도법 3),
실데이터 관측이 86건, 국립환경과학원 API 명세가 71건이다.
발표에서 "법령 기반"을 주장할 때 이 비율을 알고 말할 것. `export_ontology.py --exclude-inferred`로
미검증분을 뺀 사전으로도 돌려보고 매핑률 차이를 확인하면 방어가 단단해진다.

**③ 근거 없는 3항목**: `폼산`(rejected — 초안에 있었으나 별표 13 19쪽 전문 어디에도 없어 폐기),
`수위`·`유량`(draft — 수질 항목이 아니라 수문 관측값이라 법령 근거가 다른 축)

**④ 폐기된 표기 5건**: `질소(총)`, `인(총)`, `유분(광유)`, `유분(동식물유지)`, `Cr(VI)` —
괄호를 떼면 다른 항목과 충돌해서 `review_status=rejected`로 남겨둠. 폐기도 근거와 함께 기록돼 있다.
