# "조직별 용어사전은 매번 사람이 새로 구축해야 한다" — 문제 실재성 근거 자료집

> 주장: 기술(매칭 알고리즘)이 없어서 SI 발주가 반복되는 게 아니라,
> **조직마다 용어·표준이 달라 "그 조직의 사전"을 사람이 수작업으로 구축·유지해야 하기 때문에** 표준화 사업이 반복 발주된다.
>
> 결론: **실재하는 문제가 맞다.** 학계는 25년째 "완전 자동화 불가, human-in-the-loop 필수"를 결론으로 내고 있고,
> 업계는 실패율·비용 데이터로, 한국 정부는 제도(매년 표준용어 제·개정, RFP 의무화)로 이를 입증한다.
> 수질 도메인 직접 근거(환경공학회지 논문)도 존재한다.

작성: 2026-08-07. 아래 자료는 전부 웹에서 실제 확인한 것이며, 원문 미확인(2차 인용 등)은 표시함.

## 1. 학술 근거 — "스키마 매칭 완전 자동화는 안 된다"

| # | 자료 | 출처/연도 | 핵심 내용 |

| 1-6 | The Data Civilizer System (MIT, Stonebraker 외) | CIDR, 2017 | 데이터 과학자가 시간의 80%를 데이터 찾기·준비·통합·정제에 쓴다는 통계를 인용하며, 80%는 하한일 수 있다고 지적 — 제약사 Merck 데이터 책임자는 자사 기준 98%로 추정. https://www.cidrdb.org/cidr2017/papers/p44-deng-cidr17.pdf |

## 2. 해외 업계 근거 — 실패율·비용·빅테크 사례

### 시간·비용 통계
- **CrowdFlower 2016 설문** (Forbes 기사): 데이터 과학자 시간의 60% 정제 + 19% 수집 ≈ 80%가 데이터 준비. https://www.forbes.com/sites/gilpress/2016/03/23/data-preparation-most-time-consuming-least-enjoyable-data-science-task-survey-says/ ("80%" 수치의 원출처. 반론 글도 있으므로 "CrowdFlower 설문 기준"으로 명시할 것)
- **Anaconda State of Data Science 2020/2021**: 데이터 준비·정제에 39~45% — 모델 학습·선택·배포를 합친 것보다 많음. https://www.anaconda.com/resources/whitepaper/state-of-data-science-2020
- **Semarchy**(MDM 벤더): MDM 구현에 6개월~2년. 고객 조사에서 59%가 1~2년 소요 예상. https://semarchy.com/blog/mdm-implementation/
- **Binmile**: 엔터프라이즈 MDM 구현 $300K~$3M+, 컨설팅(데이터 모델링·거버넌스·변화관리)만 £100K~£1M+. https://binmile.com/blog/mdm-implementation-cost/

### 실패율 (Gartner)
- Gartner 보도자료(2024-02-28): **2027년까지 데이터·분석 거버넌스 이니셔티브의 80%가 실패할 것**으로 예측. https://www.gartner.com/en/newsroom/press-releases/2024-02-28-gartner-predicts-80-percent-of-data-and-analytics-governance-initiatives-will-fail-by-2027-due-to-a-lack-of-a-real-or-manufactured-crisis-
- Dataversity(Gartner 인용): MDM 프로그램의 75%가 비즈니스 목표 충족 실패. 주원인은 지표·거버넌스 부재 = 사람·프로세스 문제. https://www.dataversity.net/articles/common-master-data-management-mdm-pitfalls/ (Gartner 원문은 유료라 2차 인용임을 명시할 것)

### 빅테크가 자체 데이터 카탈로그를 만든 이유 (공식 기술블로그)

- Spotify Lexikon (2020): 소유권·문서화 부재로 전문가에게 직접 묻는 방식에 의존하다 구축. https://engineering.atspotify.com/2020/02/how-we-improved-data-discovery-for-data-scientists-at-spotify

### 정부 제도 자체가 문제의 증거

## 4. 유튜브 댓글 조사 (2026-08-07 수행)

- 방법: yt-dlp로 뉴스·직군 영상 23개(공공데이터 품질, 차세대 복지시스템 먹통, 행정전산망 마비, 4세대 나이스 오류, SI/데이터 직군, 공무원 실무, 데이터 라벨링)의 공개 댓글 약 1,600개 수집 → 키워드(표준/취합/이관/수작업/매핑 등) 필터 후 수동 확인.

- **한계 (정직하게)**: "용어사전/컬럼 표준화 때문에 고생했다"는 **직접적** 경험담은 유튜브 댓글에서 찾지 못함. 이 고통은 일반 대중이 아니라 DBA·DA·SI 컨설턴트의 것이라 유튜브 뉴스 댓글보다 **개발자 커뮤니티(블라인드, OKKY, 커리어리, 브런치의 DA 회고글)** 에 있음. 발표에서는 유튜브 댓글을 "현장 피해의 정황 증거"로만 쓰고, 본 증거는 1~3절 자료를 쓸 것.

## 5. 인터뷰 권장 대상

자료가 이미 충분하므로 인터뷰는 "숫자 확보"보다 **"우리 도메인(수질)의 생생한 한 줄 증언"** 확보 목적으로 1~2건이면 충분.

| 우선순위 | 대상 | 물어볼 것 | 접근 방법 |
|---|---|---|---|
| ★★★ | **지자체 보건환경연구원 수질검사 부서** 또는 **유역환경청 측정망 담당** | 타 기관 데이터 받을 때 항목명·단위·양식이 얼마나 제각각인지, 취합에 몇 명이 몇 시간 쓰는지 | 학교(캡스톤 지도교수) 명의 공문/이메일, 또는 공공데이터포털 데이터 문의 채널 |
| ★★★ | **국립환경과학원 물환경정보과** (물환경정보시스템 운영) | 시스템에 기관 데이터를 연계할 때 표준화 작업을 누가 어떻게 하는지, 신규 기관 연계에 걸리는 기간 | 물환경정보시스템 대표 문의처 → 담당자 연결 요청 |
| ★★ | **데이터 컨설팅사 DA 컨설턴트** (엔코아·비투엔 등) | 표준사전 구축 프로젝트의 실제 공수(인원×개월), 어떤 작업이 자동화가 안 되는지 | 커리어리/LinkedIn 콜드 메시지, 데이터야놀자·SLASH 등 컨퍼런스 현장 |
| ★★ | **NIA 공공데이터 품질관리 담당** | 공통표준용어를 매년 제·개정하는 이유, 기관들의 표준 미준수 실태 | NIA 대표 문의, 공공데이터 품질관리 교육/세미나 참석 후 질문 |
| ★ | **K-water 디지털플랫폼/데이터 부서** | 물 데이터 표준화를 내부에서 어떻게 하는지 | K-water 열린혁신 채널, 산학 프로그램 |
| ★ | **차세대 시스템을 겪은 실사용자** (교사·사회복지 공무원 지인) | 데이터 이관 후 현장에서 겪은 일 | 지인 네트워크 — 나이스/복지시스템 사례는 댓글로도 이미 정황 확보됨 |

인터뷰 공통 질문 예시:
1. 다른 기관(부서) 데이터를 받을 때 컬럼명·단위가 우리와 다른 경우가 얼마나 자주 있나요?
2. 그걸 맞추는 작업은 누가, 어떤 도구로, 얼마나 걸려서 하나요?
3. 그 매핑 규칙(이 기관의 'BOD5'는 우리의 '생물화학적산소요구량')은 어디에 기록되나요? 담당자가 바뀌면 어떻게 되나요?
4. 표준화 용역/시스템 구축을 해봤다면, 끝난 뒤에도 새 데이터가 들어올 때 같은 문제가 다시 생기지 않았나요?

질문 4번이 핵심 — "구축이 끝나도 사전 유지가 계속 사람 일로 남는다"는 답이 나오면, 우리의 "성장하는 사전(리뷰 루프)"이 정확히 그 지점을 겨냥한다는 스토리가 완성된다.

## 6. 발표 활용 요약

- 문제 정의 슬라이드: 환경공학회지 2017(수질 도메인 직접 근거) + 행안부 공통표준용어 9,027개(정부 공인) 
- 시장성 슬라이드: Gartner 80% 실패 예측 + 엔코아 인터뷰(컨설턴트 10명·10개월) + MDM 비용($300K~$3M)
- 기술 타당성 슬라이드: Bernstein 2011(자동화 한계) + LLM 매칭 2024(검증 전제) → "그래서 우리는 exact 사전 우선 + 유사도는 후보만 + 사람 확정 + 사전 성장" 설계
- 주의: "세계 최초" 표현 금지. "80% 시간" 인용 시 출처(CrowdFlower 설문) 명시. Gartner 2차 인용은 원문 유료임을 각주로.
