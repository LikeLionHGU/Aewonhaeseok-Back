Demo Scenario

수질 데이터 표준화 서비스
시연 영상 대본

애매한 현장 데이터를 업로드해 용어를 표준화하고, 법적 기준에 따라 분석한 뒤 Open API로 기업 시스템까지 연결하는 전체 시연 흐름입니다.

권장 길이 5분 내외 표준화 + 검토 수질 분석 Open API 발급
로그인 → 파일 업로드 → 자동 매핑 → 사용자 검토 → 지역·규모별 분석 → Open API 키 발급 → 기업 시스템 연동
01

서비스 소개

0:00–0:25

화면: 메인 화면 또는 서비스 소개 화면

기관과 기업마다 서로 다른 형식으로 작성된 수질 데이터는 통합과 분석에 많은 수작업이 필요합니다. 저희 서비스는 수질 데이터의 용어를 표준화하고, 법적 배출허용기준을 바탕으로 데이터를 분석하며, 기업이 자체 시스템에서도 기능을 사용할 수 있도록 Open API를 제공합니다.

02

로그인과 사용자별 데이터 관리

0:25–0:45

화면: 로그인 후 대시보드 진입

먼저 사용자 계정으로 로그인합니다. 업로드한 파일과 매핑, 검토 및 분석 기록은 계정별로 분리되어 다른 사용자의 데이터와 섞이지 않습니다.

촬영 시 실제 비밀번호가 노출되지 않도록 자동 완성을 사용하거나 입력 장면을 편집하세요.

03

애매한 수질 데이터 업로드

0:45–1:10

화면: 애매한_수질용어_시연.xlsx 선택 후 업로드

실제 현장에서는 표준 명칭뿐만 아니라 축약어와 오타, 기관별 표현이 함께 사용됩니다. 이번에는 이러한 애매한 항목이 포함된 엑셀 파일을 업로드해 보겠습니다.

파일에는 BOD처럼 명확한 항목과 함께 ‘생물학산소요구’, ‘화학적산소’, ‘총질쏘’처럼 표준 명칭과 다른 표현이 포함되어 있습니다.

04

자동 매핑 결과

1:10–1:50

화면: 컬럼별 매핑 결과와 상태별 개수

업로드된 컬럼은 표준 사전과 비교되어 정확 매핑, 자동 매핑, 검토 필요, 미매핑 상태로 분류됩니다. 측정일자와 BOD는 정확히 매핑됐고, 사업장명과 생물학산소요구는 유사도에 따라 각각 ‘사업장 명칭’과 ‘생물학적 산소요구량’으로 자동 매핑됐습니다.

2정확 매핑
2자동 매핑
3검토 필요
4미매핑
05

애매한 항목 검토

1:50–2:30

화면: 검토 필요 항목의 추천 후보와 유사도 점수

신뢰도가 충분하지 않은 항목은 시스템이 임의로 확정하지 않고 검토 대상으로 분리합니다. 사용자는 추천 항목과 유사도 점수를 확인해 결과를 승인하거나 직접 수정할 수 있습니다.

화학적산소→화학적산소요구량 추천
방류구번호→방류구 추천
클로로필농도→클로로필 추천

반면 ‘현장메모’와 같이 측정 항목인지 불분명한 데이터는 미매핑으로 남겨 잘못된 자동 변환을 방지합니다.

06

수질 데이터 분석

2:30–3:30

화면: 분석 대상 선택 → 지역·사업장 규모 선택 → 분석 실행

표준화가 완료된 데이터는 별도의 재가공 없이 수질 분석에 활용할 수 있습니다. 배출허용기준은 지역과 사업장 규모에 따라 달라질 수 있으므로, 분석 조건에서 청정지역, 가지역, 나지역과 같은 지역 구분과 사업장 규모를 선택합니다.

분석을 실행하면 측정값과 법적 배출허용기준을 비교하여 각 항목의 상태를 판정합니다. 예를 들어 BOD 측정값과 선택한 지역 및 규모에 해당하는 기준치를 비교해 정상 또는 기준 초과 여부를 확인할 수 있습니다.

결과에는 단순한 판정뿐만 아니라 적용된 기준값과 지역, 사업장 규모, 법적 근거가 함께 제공됩니다. 이를 통해 사용자는 어떤 기준으로 결과가 도출됐는지 확인할 수 있습니다.

화면에 표시되는 상태 명칭이 ‘정상·주의·초과’와 다르면 실제 화면의 명칭을 그대로 읽으세요.

07

분석 기록 확인

3:30–3:50

화면: 분석 기록 또는 데이터 활용 기록

수행한 분석은 사용자 계정에 저장됩니다. 사용자는 이전 분석 결과와 적용 기준을 다시 확인할 수 있으며, 다른 계정의 기록은 조회할 수 없습니다.

08

Open API 소개

3:50–4:15

화면: Open API 소개 페이지

기업이 저희 웹사이트를 직접 사용하지 않아도 기존 업무 시스템에서 같은 기능을 활용할 수 있도록 Open API도 제공합니다. 기업은 Open API를 통해 수질 데이터의 컬럼 매핑, 추천 후보 확인, 파일 단위 표준화와 검토 결과 반영 기능을 자사 시스템에 연동할 수 있습니다.

09

Open API 키 신청 및 발급

4:15–4:50

화면: 조직명·사용 목적·요청 한도 입력 → API 키 발급

사용자는 조직명과 API 사용 목적, 요청 한도 등의 정보를 입력해 API 키를 발급받습니다. 발급된 키는 기업을 식별하고 호출 권한과 사용량을 관리하는 데 사용됩니다.

보안을 위해 발급된 원본 키는 처음 생성됐을 때만 확인할 수 있으므로 안전한 곳에 보관해야 합니다.

영상에는 실제 운영용 API 키 전체를 노출하지 마세요. 중간 부분을 가리거나 촬영 후 즉시 폐기할 시연용 키를 사용하세요.

10

Open API 사용 방법

4:50–5:15

화면: 사용 안내 또는 Swagger API 문서

기업은 발급받은 키를 요청 헤더의 X-API-Key에 입력해 API를 호출할 수 있습니다. 컬럼 목록이나 파일을 전달하면 표준코드, 추천 항목, 매핑 상태와 유사도 점수를 응답받을 수 있습니다. 따라서 기업은 기존 데이터 관리 시스템이나 업무 프로그램에 수질 데이터 표준화 기능을 직접 연결할 수 있습니다.

X-API-Key: 발급받은_API_KEY
11

마무리

5:15–5:35

화면: 메인 화면 또는 전체 기능 요약 화면

저희 서비스는 수질 데이터의 용어를 자동으로 표준화하고, 애매한 항목은 사람의 검토를 거쳐 정확도를 보완합니다. 표준화된 데이터는 법적 기준을 기반으로 분석할 수 있으며, Open API를 통해 기업의 기존 시스템에도 연동할 수 있습니다. 이를 통해 수질 데이터 정리부터 검토, 분석, 시스템 연동까지 하나의 흐름으로 제공합니다.

발표 핵심 문장 “확실한 데이터는 자동으로 처리하고, 애매한 데이터는 사람의 검토로 보완하며, 표준화된 결과를 분석과 Open API까지 연결합니다.”
